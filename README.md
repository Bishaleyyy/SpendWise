# SpendWise — Expense Tracker

A clean, responsive expense tracker built with HTML, CSS, and vanilla JavaScript. SpendWise helps users track income, expenses, and their remaining balance in one simple dashboard.

## 🚀 Live Demo

[Open SpendWise](https://bishaleyyy.github.io/SpendWise/)

## ✨ Features

- View total balance, income, and expenses
- Add and delete transactions
- Automatically update financial summaries
- Save transactions using browser LocalStorage
- Responsive and easy-to-use interface
- Basic input validation

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## 💻 Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Bishaleyyy/SpendWise.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
